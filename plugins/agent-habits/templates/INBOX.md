# Inbox (not-yet-tasks)

The one list of problems, ideas and maybe-laters that aren't decided work yet. The user ranks it. An item leaves
when it becomes a task (the scheduler's `Queue:` call writes it in [tasks/](tasks/README.md) and deletes the line
here) or when it's dropped (git history keeps it). One line per item: what, why, link to the evidence.
